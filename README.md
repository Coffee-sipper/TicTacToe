
# Tic-Tac-Toe AI

A Python implementation of Tic-Tac-Toe featuring the Minimax algorithm and Alpha-Beta Pruning for optimal decision-making.

## Features

- Interactive Tic-Tac-Toe game.
- Minimax algorithm for optimal move selection.
- Alpha-Beta Pruning to reduce unnecessary game-state evaluations.
- Comparison of both algorithms based on the number of evaluated positions.
- Bonus implementation with improved move ordering.

## Algorithms

### Minimax
Explores possible game states to determine the best move, assuming both players play optimally.

### Alpha-Beta Pruning
Optimizes Minimax by skipping branches that cannot influence the final decision.
